## 📌 Projects Included

### 1. **AI Chatbot – Natural Language to SQL**
An AI-powered chatbot that interprets natural language questions (in Romanian or English) and transforms them into **SQL queries** for a custom multi-table organizational database I designed.

- **Purpose:** Help beginner employees perform internal tasks (e.g., creating financial orders) without knowing SQL syntax.  
- **Features:**
  - Understands Romanian and English queries.
  - Converts plain questions into executable SQL commands.
  - Built using **Python** with Hugging Face integration for NLP.
  - Runs on a **Modal** server and is accessed via an external API.
- **Status:** Core functionality complete, PHP/web interface integration planned.

**Run / Deploy Instructions:**
```bash
# Deploy the chatbot to Modal
modal deploy main.py

# Run locally for testing
modal run main.py::test

# Run main application locally
modal run main.py::main
````

Once deployed, the chatbot can be accessed via the provided API endpoint.

### 2\. **Romica Tie Group Website**

A company website designed to present products, services, and solutions for Romica Tie Group.

  - **Purpose:** Provide a modern, responsive web presence for the company.
  - **Features:**
      - Pages: Home, About Us, Solutions, Quality Compliance, and more.
      - Responsive HTML/CSS/JavaScript frontend.
      - Powered by **Vite** for fast local development.
  - **Status:** Active development — recently added Solutions and Quality Compliance pages.

**Run Locally with Vite:**

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Then open the provided local URL in your browser.
