  - title: Rework and reuse
    body: Serviceable components returned to service.
  - title: Upgrade
    body: Control system, instrumentation, brake, hydraulic circuit, safety systems or capacity, carried out during the rebuild.
  - title: Test
    body: Static proof load, dynamic functional load, brake holding, render and speed tests to 150 Te, as for a new machine.
  - title: Documentation
    body: Quality Record Book and User and Maintenance Manuals reissued to the as-rebuilt condition.
  - title: Spares recommendation
    body: Based on measured component condition.
