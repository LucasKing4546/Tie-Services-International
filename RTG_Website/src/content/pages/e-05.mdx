## The slip ring boundary, explained

It looks like a gap in the scope. It is the opposite.

The slip ring is where the winch joins the vehicle's data and power
architecture, fibre count, conductors, voltage, protocol, tether
termination. All of that is set by the vehicle, not by the drum. A
supplier who picks it for the buyer is guessing, and the guess does not
show up in the factory, it shows up at commissioning, or on the first
dive. A failing slip ring is also one of the few faults that costs a day
twice: intermittent video and telemetry look like a vehicle problem, so
the search starts in the wrong place.

So the winch is designed to accept the unit specified. We procure it, fit
it and function-test it with the machine, so one tested assembly still
ships from one supplier, we just do not decide which slip ring the ROV
should be talking through.

## Cable protection

Lebus shell grooving and controlled level wind on every winch in this
family, because the umbilical is usually worth more than the winch that
handles it. A plain drum lets rope wander, cross over and crush the layers
beneath it. It is the fastest way to destroy an expensive umbilical. A Lebus
grooved shell forces each turn into a parallel path and moves the
crossover into a controlled zone; the level wind places the rope rather
than letting it fall, which matters most at the speeds an ROV deployment
actually runs at.

The level wind is electrically actuated, PLC controlled, automatic with a
manual override, and adjustable to accept a range of cable diameters, so
the same frame can be set up for the umbilical actually being run rather
than the one the winch happened to ship with.
