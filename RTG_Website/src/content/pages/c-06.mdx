- Mutual NDA issued before drawings are exchanged, on request the same day
- Client documentation held in segregated project files with restricted access
- No client design used in, or developed into, RTG products
- Documentation returned or destroyed at contract end, as specified
- Separation from RTG's own range written into the contract, with defined scope and remedy

RTG's own general arrangement drawings are issued only to named recipients, watermarked and serialised.
